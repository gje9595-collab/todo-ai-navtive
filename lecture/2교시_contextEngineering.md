# 2. AI Native Engineering

## 2-2. context Engineering

### 2-2-1. 컨텍스트 엔지니어링이란?
- 컨텍스트 엔지니어링(Context Engineering)은 `AI Agent(멀티턴을 가진 LLM)가 작업을 수행하는 데 필요한 정보를 적절한 시점에 제공하고 관리하는 핵심 기술`입니다.
- LLM이 컨텍스트를 바탕으로 응답을 생성한다면, AI Agent는 컨텍스트를 바탕으로 판단하고, 도구를 선택하고, 작업을 수행하며, 다음 행동을 결정합니다.
- 즉, 컨텍스트 엔지니어링은 AI Agent가 올바르게 행동할 수 있도록 정보 환경을 설계하는 기술이라고 볼 수 있습니다.

```text
[단일 턴 LLM]
질문 → LLM → 응답


[멀티턴 LLM]
질문 → LLM → 응답
         ↑
    이전 대화 이력


[AI Agent]
        사용자 목표
             ↓
      Context 구성
             ↓
       LLM 판단
             ↓
        도구 실행
             ↓
        결과 확인
             ↓
      Context 갱신
             │
             ├── 목표 미달성 → LLM 재판단
             │
             └── 목표 달성 → 최종 결과
```
- LLM이 단일 턴에서 멀티턴 대화로 확장되면서 `이전 대화의 문맥을 유지하는 것이 중요`해졌고, 이를 활용한 `AI Agent가 목표 달성을 위해 판단과 도구 실행을 반복`하면서 `컨텍스트의 지속적인 관리가 더욱 중요`해졌습니다. 이러한 정보의 선택·구성·갱신·압축을 체계적으로 설계하는 기술이 컨텍스트 엔지니어링입니다.
- 즉, 멀티턴은 컨텍스트의 연속성을 요구하고, AI Agent의 반복 실행은 컨텍스트의 동적인 관리를 요구한다


#### 프롬프트 엔지니어링 vs 컨텍스트 엔지니어링

| 구분 | 프롬프트 엔지니어링 | 컨텍스트 엔지니어링 |
|---|---|---|
| 핵심 질문 | 어떻게 요청할 것인가? | 어떤 정보를 제공할 것인가? |
| 주요 대상 | 지시문, 역할, 출력 형식 | 지시문, 문서, 대화 이력, 검색 결과, 도구 결과 |
| 주요 기술 | Zero-shot, Few-shot, 단계별 프롬프팅 | RAG, 메모리, 컨텍스트 압축, 정보 선택 |
| 목적 | 원하는 응답 유도 | 정확한 판단에 필요한 정보 제공 |
| 적용 범위 | 개별 요청 중심 | 전체 LLM 실행 과정 |

두 기술은 서로 대체하는 관계가 아니라 함께 사용됩니다. 프롬프트도 컨텍스트를 구성하는 요소 중 하나입니다.

**▼ 표  에이전트가 매 요청마다 처리하는 정보들**

| 구분 | 예시 |
|---|---|
| 시스템 프롬프트 | CLAUDE.md, 역할 지시 |
| 도구·스킬 정의 | 사용 가능한 도구 목록, 스킬 설명(description) |
| 대화 히스토리 | 이전 턴의 질문과 답변 |
| 도구 실행 결과 | 파일 읽기, 검색 결과, API 응답 |
| 외부 문서 | RAG로 가져온 청크(chunk), 첨부 파일 등 |
| 현재 상태 | 작업 진행 단계, 에러 메시지 |

`이 모든 것을 합쳐서 컨텍스트(context)`라고 합니다.

### 2-2-2. context 의 구성요소

- 컨텍스트는 여러 요소가 유기적으로 연결된 구조물입니다.실전에서 가장 자주 다루는 네 가지 요소인 시스템 프롬프트(system prompt), 도구 실행 결과(rool results), 검색된 지식과 외부 문서부터 살펴봅니다.

**CLAUDE.md 파일이 컨텍스트에 로드되는 방식**

클로드 코드에서는 CLAUDE.md 파일이 시스템 프롬프트의 핵심 구성 요소로 자동 로드됩니다. 프로젝트 루트에 존재하는 CLAUDE.md 파일은 세션이 시작될 때 컨텍스트의 앞부분에 주입되며, 에이전트는 이 파일에 적힌 내용을 프로젝트 전반의 규칙으로 인식합니다.   

로드 우선순위는 다음과 같습니다.

• **전역 설정**: ~/.claude/CLAUDE.md   
• **프로젝트 루트**: ./CLAUDE.md   
• **하위 디렉터리**: src/CLAUDE.md 등(해당 경로 작업 시)
