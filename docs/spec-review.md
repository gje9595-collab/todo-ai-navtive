## 6. 착수 가능 여부

- 구현을 막던 충돌(R-01)은 명세에 해결안을 반영했다. 남은 충돌(R-07)과 보안 누락(R-08)은 0단계 Task로 넘겼다.
- **0단계와 1단계(T-01~T-35)는 바로 착수할 수 있다.** 이 범위는 In-Memory 저장소와 dev 인증만 쓰므로 Q-01~Q-03과 무관하다.
- **2단계(T-20 이후)는 Q-02 확인과 Q-03 승인 후 착수한다.** 3단계는 Q-01 결정 후 착수한다.
